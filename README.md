# RiskGuard Authentication

Frontend independiente para el bounded context Usuario/Autenticacion.

## Scripts

- `npm run server`: levanta json-server en `http://localhost:3001/api/v1`.
- `npm run dev`: levanta Vue en `http://localhost:5174`.
- `npm run build`: compila el proyecto.

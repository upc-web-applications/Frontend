# RiskGuard Monitoring Dashboard

Frontend independiente para el bounded context Monitoreo/Dashboard.

## Scripts

- `npm run server`: levanta json-server en `http://localhost:3002/api/v1`.
- `npm run dev`: levanta Vue en `http://localhost:5175`.
- `npm run build`: compila el proyecto.

## Alcance

Incluye dashboard de supervisor, mapa de calor operativo, bandeja de tickets, asignacion de tecnico, mantenimiento preventivo y reportes archivados.
